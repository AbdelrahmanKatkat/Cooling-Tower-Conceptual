# Cooling Tower Designer

Static GitHub Pages app: preliminary cooling-tower sizing, a live 3D conceptual preview and an ANSYS-ready export package (STEP, DXF, Fluent journal, report).

- Pure HTML/CSS/JS, no build step or external requests; all artwork is local SVG (`assets/`, regenerated by `node tools/gen-assets.mjs`).
- Enable hosting: **Settings → Pages → Deploy from branch → `/ (root)`**.
- Sizing is a simplified energy-balance estimate (m = Q / cp·ΔT, fixed L/G and hydraulic loading) for concept studies only.

Screenshots (headless Chromium) are in `screenshots/`.
